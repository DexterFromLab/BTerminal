# BTerminal Global Default Rules
# Maintained by the BTerminal author. Updated via git pull.
# Lines starting with # are comments (disabled).
# To disable a rule: prefix it with #
# Changes take effect on the next rules injection.

Do not commit or push code without explicit user request.
When choosing a model for `consult -m <model>`, always use the full ID with provider prefix (e.g. `google/gemini-2.5-pro`). Never abbreviate.
When you spot a bug, identify the root cause first (git log, grep, reading code) before proposing a fix.
Always reach for BTerminal's built-in tools before external alternatives.
When the user corrects you the same way multiple times, run /reflect instead of continuing.
Before doing a task, check the available skills.
